# Optional source-bound diagram author

Default Live remains the freeform visual DSL. To try the diagram protocol for
this launch only in PowerShell:

```powershell
$env:FISCH_PRESENTATION_PROTOCOL = 'diagram'
fisch live
Remove-Item Env:FISCH_PRESENTATION_PROTOCOL
```

The launcher adds `diagramLab=1` to its initial browser URL; no reload is needed.
The host selects the same isolated presentation provider lifecycle with a diagram
policy, bounded public-source input and exact-substring parser. Primary Codex
receives no diagram instructions, model/effort override or output rewriting.
An invalid protocol disables only the visual lane and prints a configuration
error; native chat continues. `freeform` or an unset variable retains the default.

Diagram mode uses complete 80–320-character prose excerpts with first-seen expiry.
No suitable excerpt is an ordinary abstention. Browser admission requires the
exact issued quote, and geometry/caption share actual submitted particle bounds.
Panels below 600×420 pixels fail closed. Display waits for distinct frames with
150ms stable bounds; this consumes the original source lifetime, not extra time.

This is opt-in experimental wiring, not evidence of general semantic correctness
or lower latency. Exact substrings do not prove an arrow is entailed. Provider
unit tests use mocked RPC, and browser fixture checks do not involve real models
or cameras. The provider still cold-starts a separate process per generation.
