# Objects - locate owners and first-order effects

## Inputs
- Working: a requested change and its source diff.
- Reference: [map schema](../CONTEXT.md) and one matching card below.

## Process
1. Open [expression](expression.md), [conversation](conversation.md), or
   [Live body](live-body.md), not all three by default.
2. Verify cited symbols in source and follow only relevant impact links.
3. Update the card when ownership changes; do not copy API field inventories.

## Outputs
Verified or explicitly stale object cards, with revision and source links.

## Check
Cold reviewer can find the owning source and relevant test from a single card.
Record the result in PR evidence. A future new card follows the same headings
as these cards; no placeholder clusters are created.
