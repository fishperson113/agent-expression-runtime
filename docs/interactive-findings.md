# Interactive expression findings

This log separates product experiments from open concurrency research. It does
not certify human enjoyment, physical-camera understanding or canonical provider
cancellation. Use the simplest reproducible component or implementation that
helps Fisch communicate; novelty is not a selection criterion.

## Priority decision — 2026-11-10

Prioritize an engaging proactive loop and agent-authored expression: the agent
can retain a useful form, transform it, create a new silhouette/composition,
choose any RGB color, or mix an optional avatar with authored additions. No
context/gesture-to-phrase, shape or color table is the desired behavior. Existing
permission, bounded DSL, user-priority, Stop and stale-publication safeguards
remain in force. Perfect interruption/continuity and server terminal ACK are
separate research questions, not prerequisites for a formative expression pilot.

## Next formative expression pilot

Use actual user-conversation input for textual context. A camera-only observer
receiving geometry cannot know the meaning of a public text scenario unless a
separate authorized context path supplies it. Do not disguise text as camera data
or assume the observer knows the main agent's task.

Freeze the candidate policy/catalog before a small finite development batch.
Give no named target object, color or effect; permit quiet/retain. Keep one attempt
per case and every outcome, including silence, errors and unrun cases. Review the
rendered output under opaque IDs before revealing the input, then assess
relevance/restraint/pleasantness and caption consistency. Record actual visible
change timing separately from admission, logical completion and full-turn time.
A geometry count alone is not usefulness or fun. Human acceptance remains an
explicit formative review, not a synthetic score.

## Observer authoring affordance candidate

Source audit found that MAIN already receives the rich Live authoring bundle,
while the separate Native observer only receives a generic observation policy.
The observer schema allows composition but its instructions did not explain
mechanical shape/base semantics or the unknown current appearance. A small
observer-only brief now derives supported part kinds and bounds from the existing
composition schema, explains free RGB/bounded motion and permits retain/silence.
It does not copy MAIN task context, add tools or prescribe a response to a cue.
The fixture proves curve/patch/motion/RGB contract roundtrip, not actual model
choice, recognizable rendering or enjoyment. Test this candidate with actual
observer input separately from the six public text contexts sent through MAIN.
An animate payload with empty controls/poses is contract-valid but cannot by
itself establish new visible movement or expressive usefulness.
