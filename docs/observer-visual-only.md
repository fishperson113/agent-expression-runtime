# Camera observer: visuals only

The browser does not publish camera-observer generated text to chat, whether
that observer admits a visual action or chooses an observation-only result.
The delivery receipt reports `chatPublished: false`. This is enforced at the
browser publication boundary, not merely requested in a model prompt.

Camera observations and valid visual reactions remain available. Native Codex
owns conversational answers; its public text still reaches the chat panel.
This does not claim that every legacy observer model stops producing internal
reply strings, or that native camera accuracy has been independently verified.
